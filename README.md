# Лексика — карточки английских слов

Локальное Android-приложение на Kotlin и Jetpack Compose для русскоязычного изучения слов. Данные хранятся в Room на устройстве; аккаунта, сервера и разрешения на доступ ко всему хранилищу нет.

## Что реализовано

- Папки и колоды: создание, переименование, удаление с подтверждением, перемещение колоды.
- Карточки с английским словом, транскрипцией и русским переводом; можно добавить вручную или импортировать из XLSX.
- Занятие всеми карточками колоды либо карточками, чей срок повтора наступил. «Повторить» ставит карточку через 10 минут и возвращает её в конец текущего занятия.
- Интервалы ответов «Знаю»: 1, 3, 7, 14 дней, затем удвоение до максимума 365 дней. «Выучено» — интервал не менее 21 дня.
- XLSX: выбор листа через системный SAF-пикер, распознавание русских и английских заголовков, ручное назначение столбцов, предпросмотр, выбор колоды, отметка дублей и выбор — пропустить ли их.
- Статистика: всего, выучено, срок повтора наступил, изучено сегодня.

## Сборка APK

GitHub Actions автоматически собирает debug APK при отправке изменений в `main`. Готовый `app-debug.apk` появится в разделе **Actions → Android APK → Artifacts**. Сборку также можно запустить вручную через **Actions → Android APK → Run workflow**.

Для локальной сборки откройте проект в Android Studio с JDK 17 и Android SDK Platform 36, затем выполните `gradle assembleDebug` (Gradle 8.13). APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Слои

- `data/` — Room-сущности, DAO, расписание и репозиторий.
- `importer/` — заменяемый интерфейс `SpreadsheetReader` и лёгкое чтение OOXML через Android ZIP/XML API.
- `AppViewModel.kt` — состояние занятия и предварительный просмотр импорта.
- `MainActivity.kt` — Compose UI.

Парсер рассчитан на обычные `.xlsx`-книги: листы, общие строки, inline-строки и значения ячеек. Макросы, формулы с пересчётом и старый формат `.xls` не поддерживаются.
